================================================================================
NOVI API ENDPOINTI
================================================================================

POST /api/auth/register
- Validira CAPTCHA
- Kreira korinika sa emailVerified=false
- Generiše token
- Pošalje email
Response: { success: true, memberId: "...", message: "..." }

GET /api/auth/verify-email?token=TOKEN
- Validira token
- Provjerava vremenski rok
- Postavlja emailVerified=true
- Briše token
Response: Redirect na /auth/email-verified?success=true/false

POST /api/auth/resend-verification
- Prima email
- Kreira novi token
- Pošalje novi email
Response: { success: true, message: "..." }

================================================================================
SIGURNOSNI MEHANIZMI
================================================================================

✅ CAPTCHA - server-side validacija
   - Hcaptcha token se validira sa hCaptcha serverom
   - CAPTCHA secret key nikad nije u frontendu

✅ Email Verifikacija - token-based
   - Tokeni su kriptografski sigurni (32 bajta)
   - Tokeni se brišu nakon verifikacije
   - Tokeni imaju vremenski rok

✅ Lozinka - bcryptjs
   - Sve lozinke se hash-uju
   - Nema plain-text lozinki u bazi

✅ Email - unique constraint
   - Ista email adresa se ne može registrirati dva puta
   - Constraint je u bazi

✅ Login - validacija
   - Neverificirani korisnici ne mogu da se prijave
   - Jasna error poruka o verifikaciji
